# Tafseer source verification

`source_manifest.json` is intentionally conservative. It records the five requested works but marks rights, coverage, and offline status as unverified. No source text is bundled by this manifest.

The `spa5k/tafsir_api` license is an MIT software license whose text refers to the software and associated documentation. It does not by itself establish that the embedded Urdu tafseer text is licensed for redistribution. The Ibn Kathir corpus directory is therefore not treated as an authorized text source. The other four requested books have no independently verified authorized source in this repository audit.

Do not change a source to authorized or publish/download its text until the publisher/rightsholder provides an explicit license or written permission, and the complete ayah mapping has been validated against QuranData's surah and ayah counts. Coverage fields must be computed from that validated dataset; never estimate them.
